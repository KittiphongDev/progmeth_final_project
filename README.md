# 🟢 Slime Warz

**Slime Warz** is a maze-based bomb strategy game inspired by classic **Bomber-style gameplay**.  
Players control slime characters and place bombs to destroy walls, collect items, and complete objectives.

The game supports both **Single Player** and **Two Player Battle Mode**.

---

# 🎮 Game Features

- 🧩 Random maze generation  
- 🧱 Destructible walls  
- 🚪 Hidden exit (Single Player mode)  
- 💣 Bomb placement system  
- 💥 Explosion mechanics  
- 🎁 Collectible power-up items  
- 🔊 Sound effects and background music  
- ⚔️ Two-player battle mode  

---

# 🕹️ Game Modes

## 👤 Single Player Mode
The player must **find the hidden exit within 90 seconds** by destroying walls using bombs.

## 👥 Two Player Mode
Two players compete by **placing bombs to eliminate each other**.

---

# ⌨️ Controls

### Player 1
| Key | Action |
|----|------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| Space | Place Bomb |

### Player 2
| Key | Action |
|----|------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| Enter | Place Bomb |

# 🎯 Game States

The game can be in the following states:

- `MAIN_MENU`
- `PLAYING`
- `PAUSED`
- `GAME_OVER`
- `YOU_WIN`
- `P1_WIN`
- `P2_WIN`
- `DRAW`

# 🚀 How to Run

1. Clone the repository

```
git clone <repository-url>
```

2. Open the project in **IntelliJ IDEA**
3. Run **Main.java**
4. The **JavaFX game window** will start
